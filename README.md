
# Love for Mena ✦

A personal romantic website built with HTML, CSS, and vanilla JavaScript.

## Features

- Animated starry background
- Responsive mobile navigation
- Dark and light themes
- Interactive wish button
- Love letter page
- Editable story timeline
- Memory gallery
- Personal note page
- No framework or build step required

## Project structure

- `index.html` — home page
- `love-letter.html` — letter page
- `our-story.html` — story timeline
- `memories.html` — photo gallery
- `apology.html` — personal note
- `css/style.css` — shared styles
- `js/main.js` — interactions
- `assets/memories/` — personal photographs

## Run locally

Open `index.html` in a browser, or start a local server:

```powershell
py -m http.server 8000
```

Then visit http://localhost:8000.

Press Ctrl+C in the terminal to stop the server.

## Deployment

This is a static website and can be deployed with GitHub Pages.
