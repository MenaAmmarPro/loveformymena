
# Love for Mena ✦

A little corner of the universe, made with love for Mena — a personal
romantic website built with plain HTML, CSS, and vanilla JavaScript.

**Live site:** https://ammar49-cyber.github.io/loveformymena/

## Features

- Animated starry background (canvas)
- Responsive mobile navigation
- Dark and light themes (remembered between visits)
- Interactive wish button
- Love letter page with a reveal animation
- Story timeline
- Memory gallery
- Personal note page
- Favicon and social share (Open Graph / Twitter) preview
- No framework or build step required

## Project structure

- `index.html` — home page
- `love-letter.html` — letter page
- `our-story.html` — story timeline
- `memories.html` — memory gallery
- `apology.html` — personal note
- `css/style.css` — shared styles
- `js/main.js` — interactions
- `assets/` — favicon and social share image
- `LICENSE` — Creative Commons BY-NC-ND 4.0

## Run locally

Open `index.html` in a browser, or start a local server:

```powershell
py -m http.server 8000
```

Then visit http://localhost:8000.

Press Ctrl+C in the terminal to stop the server.

## Deployment

This is a static website and is deployed with GitHub Pages from the
`main` branch.
